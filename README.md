## Checkpoint Site Package

Standalone static microsite for the dedicated Checkpoint domain: `checkpoints.fyi`.

Recommended published routes for `checkpoints.fyi`:
- `/` -> `index.html`
- `/terms` or `/terms.html` -> `terms.html`
- `/privacy` or `/privacy.html` -> `privacy.html`

Recommended submission URLs for SMS campaign review:
- website/program URL: the root domain
- terms URL: `/terms.html`
- privacy URL: `/privacy.html`

Before submitting:
1. Publish these files at the root of the dedicated domain or subdomain.
2. Verify the support email and business name are still correct.
3. Make sure the site is public and does not require login.
4. Use the dedicated Checkpoint URL in campaign fields instead of the general Soup homepage.

Runtime-aligned compliance text:
- HELP reply: `Checkpoint by Secret Soup Company. Reply STOP to unsubscribe. Questions: t@trysoup.xyz. Msg & data rates may apply.`
- STOP reply: `You have been unsubscribed from Checkpoint and will receive no further messages.`
